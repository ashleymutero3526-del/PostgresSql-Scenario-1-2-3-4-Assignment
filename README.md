**Scenario 1 University Library Book Loans......The university library tracks books and the number of copies available. A student may borrow one or more copies. 
Each loan is recorded, and returning it restores the available copies.
Scenario 2 Computer Laboratory Reservations......A computer laboratory has a fixed number of workstations available for each practical session. Lecturers reserve 
workstations for their classes. Cancelling a reservation releases those workstations.
Scenario 3 Student Hostel Room Allocation......A hostel has rooms with a limited number of bed spaces. Students are allocated bed spaces, and checking out 
releases them. Each allocation records the student and room
Scenario 5 Engineering Workshop Tool Loans.......An engineering workshop lends tools to students for practical work. Each type of tool has an available quantity. 
Returning tools increases that quantity**
