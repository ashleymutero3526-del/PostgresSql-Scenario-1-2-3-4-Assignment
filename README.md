** 1.Scenario 1 University Library Book Loans......The university library tracks books and the number of copies available. A student may borrow one or more copies. 
Each loan is recorded, and returning it restores the available copies.
2.Scenario 2 Computer Laboratory Reservations......A computer laboratory has a fixed number of workstations available for each practical session. Lecturers reserve 
workstations for their classes. Cancelling a reservation releases those workstations.
3.Scenario 3 Student Hostel Room Allocation......A hostel has rooms with a limited number of bed spaces. Students are allocated bed spaces, and checking out 
releases them. Each allocation records the student and room
4.Scenario 4 Campus Clinic Medicine Dispensing.....The campus clinic stores medicines and their available quantities. A clinician dispenses medicine to a student and 
records the quantity. A dispensing record entered in error can be reversed.**
